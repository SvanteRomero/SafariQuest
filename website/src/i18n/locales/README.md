`en/` is the reviewed source of truth for all UI copy on this site.

`fr/`, `de/`, `pt/` are first-pass machine translations produced during initial
i18n implementation and have **not** been reviewed by a native speaker. Treat
them as drafts pending review before customer-facing use in production.

There is no automated staleness check — when `en/` copy changes, the
corresponding `fr`/`de`/`pt` keys must be re-translated by hand.
